This page explains how to delete your account and associated data for the mobile game "Cube Zero".

1. Delete from within the game (recommended)

  1. Launch the game.
  2. Go to Base from the main screen.
  3. Open Settings.
  4. Tap the button on the Delete Account row.
  5. Choose Delete in the confirmation dialog. It is processed immediately.

Deletion cannot be undone. All progress and records are removed permanently.

2. Data that is deleted

  • Account information (anonymous account and any linked Google account)
  • Game progress (cleared stages, zone progress)
  • Ranking records (nickname, clear times)
  • All local data stored on the device

3. Data that is retained

The following may be retained for a limited period to meet legal obligations or to handle payment disputes.

  • Purchase and refund records — for the period required by applicable law
  • Server error logs — up to 90 days, in a form that does not identify individuals

4. Request by email

If you have already uninstalled the game or cannot access the app, please send a request to the address below.

haromiki@gmail.com

Please include the nickname you used in the game. We will process your request and reply within 7 business days.

本页面说明如何删除手机游戏“方块零”的账号及相关数据。

1. 在游戏内删除(推荐)

  1. 启动游戏。
  2. 从主界面进入基地。
  3. 打开设置。
  4. 点击删除账号一行的按钮。
  5. 在确认窗口中选择删除，将立即处理。

删除无法撤销。所有进度和记录都会永久消失，无法恢复。

2. 会被删除的数据

  • 账号信息(匿名账号及已关联的 Google 账号)
  • 游戏进度(已通关的关卡、区域进度)
  • 排行榜记录(昵称、通关时间)
  • 设备上保存的全部本地数据

3. 会被保留的数据

以下信息可能会因法律义务或处理支付纠纷而保留一段时间。

  • 支付与退款记录 — 相关法律规定的期限
  • 服务器错误日志 — 最长90天(以不识别个人的形式)

4. 通过邮件申请
